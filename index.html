    NEED A TEMPLATE?

    让 GPT 输出正确的数据格式

    复制下面的指令给 GPT Work，让它按网页可识别的 JSON 格式返回已核实的论文数据。

    请将最终筛选的科研论文输出为严格有效的 JSON，顶层格式为 {"papers":[...]}。每篇使用 title、doi、authors（字符串数组）、year、journal、volume、issue、pages、url、abstract、note（纯文本或分段文本）、tags（字符串数组）字段。仅输出确已核实的书目信息；不要虚构 DOI、作者、期刊或实验结论。note 应记录研究问题、实验设计、关键结果、局限性及证据位置，无法阅读全文时明确标注。不要输出 Markdown 代码围栏，也不要生成示例或测试论文。
